# RAJ FASHION - E-Commerce Platform

A comprehensive e-commerce platform built with Next.js, React, TypeScript, and Tailwind CSS.

## Frontend Features

### Customer Pages
- **Home Page**: Hero banner carousel, featured categories, trending products, new arrivals
- **Shop Page**: Product grid with sidebar filters (category, season, price, size, color)
- **Product Details**: Image gallery, size/color selectors, add to cart, related products
- **Cart**: Full cart management with quantity updates, coupon application
- **Checkout**: Multi-step checkout with address selection, payment method
- **Orders**: Order list, order details, order tracking
- **Wishlist**: Save favorite products
- **Account**: Profile management, addresses, password change

### Admin Dashboard
- **Dashboard**: Stats cards, recent orders, low stock alerts
- **Products**: List, add, edit, delete products with variants
- **Categories**: Hierarchical category management
- **Orders**: View and update order status, add tracking ID
- **Staff**: Manage staff members with permissions

### Authentication
- Login/Signup pages
- Forgot/Reset password flow
- Protected routes with middleware

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000)

## Tech Stack

- Next.js 16 with App Router
- TypeScript
- Tailwind CSS 4
- React 19
